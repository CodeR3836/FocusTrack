## 🧠 About

**FocusTrack** is a lightweight, responsive task management dashboard designed to help you stay organized and track your productivity over time.

It combines task management, progress statistics, category tracking, and a visual productivity calendar into a single cyberpunk-inspired interface.

No account.  
No backend.  
No complicated setup.

Just open it and start tracking.

---

## ✨ Features

### 📋 Task Management

- Create tasks instantly
- Assign categories
- Set task priorities
- Mark tasks as completed
- Delete tasks
- Filter tasks by:
  - All
  - Pending
  - Done

### 📊 Productivity Dashboard

Track your productivity with real-time statistics:

- Total Tasks
- Completed Tasks
- Remaining Tasks
- Overall Completion Percentage

### 📅 Productivity Calendar

A visual productivity grid lets you see your completed activity across dates.

Features include:

- Cyberpunk calendar interface
- Friday → Thursday weekday layout
- Four-month timeline view
- Current-day highlighting
- Completed-day indicators
- Custom month selector
- Previous/next year navigation
- Jump to current month
